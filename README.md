# ①課題名

ジャンケンやろうぜ！

## ②課題内容

ブラウザでコンピューターと対戦するじゃんけんゲームです。グー・チョキ・パーから手を選ぶと、コンピューターがランダムに選んだ手と、勝ち・負け・あいこの結果が表示されます。対戦回数と勝ち・負け・あいこの回数は、画面上部のカウンターで確認できます。

HTML・CSS・JavaScript（jQuery 3.7.1）で実装しています。ローカルでは `index.html` をブラウザで開くと遊べます。

## ⑤工夫した点・こだわった点

- 携帯ゲーム機を模した画面に、ドット調の文字と手のアイコンを配置しました。画面幅に応じて本体やボタンのサイズを調整しています。
- コンピューターの手を順に切り替え、切り替えの間隔を徐々に広げてから選んだ手で止めています。その後、カウンターを更新し、勝敗を点滅表示します。演出中は選択ボタンを無効にして、対戦が重ならないようにしています。
- 幅の広い画面でマウスを使う場合は、カーソルに合わせて背景が少し動きます。端末で動きを減らす設定が有効な場合、背景は動きません。
